ten github repos worth saving

hey, it's KP. you commented GITHUB, so here it is. the reel gave you five. here are all ten: what each one actually does, whether it's for you, and the exact line to install it, so you're not just starring things you'll never open.

who this is for

you, if you use ChatGPT or Claude every day and keep hearing about tools "on GitHub" without knowing what to do with them. skip the install lines if you've never opened a terminal. the first five minutes of this page still tell you which ones are worth learning that for.

github in one paragraph

GitHub is a giant public drive where people upload the things they build. a repo is one project's folder. the README is the front page that explains it. stars are bookmarks, and the count is a rough popularity signal. before you trust any repo, check three things on the front page: the star count, when it was last updated, and whether it has a licence. a repo with 50,000 stars that hasn't been touched in two years is a museum piece.

to save one properly: hit Star, then use the little arrow next to it to drop it into a list ("ai tools", "try this weekend"). lists are how you find it again in a month.

the five from the reel

1. superpowers · obra/superpowers

a pack of skills that makes coding agents work in a structured way: brainstorm, write a plan, build with tests, review, finish. it ships 15 skills (the reel said twenty, it's fifteen) and it's one of the most-starred agent projects on GitHub, past 290,000 stars when i checked. it's for you if you build anything with Claude Code and keep getting half-finished work back.

/plugin install superpowers@claude-plugins-official

2. awesome gpt image 2 · YouMind-OpenLab/awesome-gpt-image-2

a library of image prompts with the picture each one made. the reel said 500. it's well past that now, over 17,000 listed, sorted by use case, style and subject. nothing to install, you just browse and copy. if you want the newer 2.5 version, that's the VISUAL guide.

3. taskmaster ai · eyaltoledano/claude-task-master

give it a big project description and it breaks it into ordered tasks, tells you which one is next, and expands any task that's too big. it runs inside Cursor, Windsurf, Claude Code and others. you need an AI provider key, or Claude Code or Codex already set up.

claude mcp add taskmaster-ai -- npx -y task-master-ai

4. i-have-adhd · ayghri/i-have-adhd

a skill that stops your coding agent from burying the answer. it leads with the next action, numbers multi-step tasks, cuts the tangents and ends with one concrete next step. no diagnosis needed to want that. the repo's own install method is to ask your agent to install it by pasting the repo link and telling it to follow the AGENTS.md file, then run /i-have-adhd.

Install the skill at https://github.com/ayghri/i-have-adhd
by following its AGENTS.md file.

5. awesome agents · kyrolabs/awesome-agents

a curated list of open-source AI agents, around 175 entries, grouped into frameworks, software development, research, memory, automation and browser agents. it's a map, not a tool. use it when you want to know what already exists before you build something. a bigger, older list of the same kind lives at e2b-dev/awesome-ai-agents.

the five i held back

6. anthropic's skills · anthropics/skills

Anthropic's own example skills, including the ones behind Claude's Word, PDF, PowerPoint and Excel features. the best place to see what a well-written skill looks like before you write your own.

/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

7. generative ai for beginners · microsoft/generative-ai-for-beginners

Microsoft's free 21-lesson course on building with generative AI. if the reel made you feel behind, this is the structured way to catch up without paying for a course.

8. ollama · ollama/ollama

runs open models on your own laptop. no account, no usage limits, nothing leaves your machine. useful when you're working with something private, or just want to see what a local model can do.

ollama run gemma3

9. n8n · n8n-io/n8n

visual workflow automation with AI built in, the self-hosted alternative to Zapier. connect your inbox, a spreadsheet and a model with boxes and arrows. it's "fair-code", so read the licence before you build a business on it.

10. browser use · browser-use/browser-use

lets an AI agent drive a real browser: open pages, click, fill forms, pull data. it's the engine under a lot of "AI that books things for you" demos. developer-facing, but the README examples are short enough to follow.

which one first

if you only open one this week:

  • you just want better images: #2, nothing to install.
  • you want to understand AI properly: #7, one lesson a day.
  • you build with Claude Code: #1 then #4, together they fix the two biggest complaints people have about agent output.
  • you want automations running while you sleep: #9.

save the rest to a list and come back. that's Off-Script Rich: the tools are free, the edge is actually opening them.

good to know

  • star counts are a vibe, not a review. they tell you something got attention. check the last-updated date and the open issues before you install anything that touches your files.
  • plugins can run code. a skill or plugin you install into an agent can read and change files in your project. install from repos you've looked at, and keep agents out of folders with anything sensitive.
  • commands change. install lines are copied from each repo's README on 12 October 2026. if one fails, the README is the source of truth.
